# Data Cleaning & Visualization Project – Retail Sales Analysis

## Objective
Clean, process, and visualize a raw retail-sales dataset using Python.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Cleaning performed
- Checked data types, missing values, and duplicates
- Removed duplicate records
- Handled missing categorical values with mode
- Handled missing numeric values with median
- Treated impossible negative values as missing
- Detected and handled outliers using the IQR method
- Recalculated Sales after cleaning

## Visualizations
- Total Sales by Product
- Total Sales by Region
- Monthly Sales Trend
- Sales Distribution
- Correlation Heatmap

## Files
- `raw_retail_sales.csv` – raw dataset with sample data-quality issues
- `cleaned_retail_sales.csv` – cleaned dataset
- `data_cleaning_visualization.ipynb` – complete Python analysis
- `README.md` – project documentation

## Note
The raw dataset is a small practice retail-sales dataset created for this project, with intentional missing, duplicate, invalid, and extreme values so the cleaning steps can be demonstrated clearly.
